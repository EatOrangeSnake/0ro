# 0RO语言教程
## 简介
### 来源
***0ro***（***zero relates objects***）（读作*zero*）的名称的灵感来自于从无到有的设计哲学，具体哲学理念请看下一部分。
### 哲学理念
***0ro***的原子语义极其简洁，但却能构造极多逻辑性的概念，这种从零到一、从无到有的理念是***0ro***的核心理念。
### 核心理论
***0ro***参考了范畴论的设计理念，但不完全基于范畴论。
## 词法
每一行是一个语句，一行内用空格分隔后的每一个单词（包含特殊符号）都是一个标识符。

如果是特殊符号，则会优先寻找一串连续的特殊符号作为独立的标识符。

如果分隔后没有符号组成，则直接忽略并舍弃。
## 语法与语义
***0ro***中，基础单元有且只有**概念**和**关系**（类似于范畴论中的**对象**和**态射**），所有具体化的概念都是这两者派生出来的，每个概念用单独的标识符表示。一行内的所有标识符表示之间互相有**关系**。

语法（包括作用域）的解析顺序从上到下，但语义覆盖全局。
### 空行
空行无语义。
### 注释
注释一般用`#`符号开头，可放到一行的末尾。
### 概念范围
一个概念会尽可能贪心地表示所有可能的概念，除非它被约束。
### 命题成立句式
#### 关系
每行语句及子句都是一个关系（即使只是一个概念组成的关系），称为**关系语句**，代表这些概念之间是有某种关系的，即进行命题约束。关系本身也可以说成是一个概念，概念本身也可以说成是一个关系。但**概念**偏向于本身，而**关系**还侧重了其有更精细的组成部分。

一般来说，一个关系内的所有概念是互相无序的。但为了便于表示，如果按照某个顺序排列的关系中某些概念被约束了，那么如果再组合出了这样的顺序，则这个组合的关系及其被组成的概念的约束也可被复用，而像这种关系的组合判定是有序的。
#### 因变量
当一个概念没有被**固定**时，意味着它就是被其他条件约束的因变量。
#### 自变量
当一个概念被**固定**时，那么它就是约束其他条件的自变量，但固定化后会保留之前作为因变量的约束。
#### 固定转换
每行的语句（非子句）代表的关系都可以被**固定**或**释放**，即在同个模块内，因变量转义为自变量或自变量转义为因变量，且该语句被称为**固定语句**。同一模块内，没有被转换的所有概念默认都是因变量。
#### 举例说明
考虑以下代码（摘自标准库文件`./std/math/category/sufficient.0ro.txt`）：
```0ro
conclusions relations # 表示因变量`conclutions`和`relations`有关联。
relations # 固定`relations`，让它作为自变量，但仍然限制它与`conclutions`有关。
conditions relations # 表示自变量`conditions`和因变量`relations`有关系。

conditions sufficient conclusions # 表示对于任何这样的句式，都会填充句中概念使得满足相关的命题。
```
这段代码定义了一个**充分推导**关系，表示“如果有一个自变量`conditions`，那么因变量`conclusions`就一定是满足`conditions`的一个概念”，即`conclusions`是所有满足`conditions`约束的概念组成的集合的子集。
### 语法糖
#### 子句
我们可以使用**子句语法**让任何关系代指一个概念，并且在一个句子内用小括号、中括号或花括号作为分隔符（建议使用花括号）。
##### 举例说明
考虑以下代码：
```0ro
I like oranges best
```
如果我们不知道我喜欢什么，那么想要获取喜欢什么就得这么写：
```0ro
I like {my favourate food} best
I eat {my favourate food}
```
这需要先定义一个中间概念`my favourate food`，然后再使用，很麻烦。
但是，如果我们能再加上：
```0ro
I like {what I like best} best
```
那么解析器就会发现`what I like best`代指的概念和`oranges`完全等价，此时就可以这样使用：
```0ro
I eat {what I like best}
```
#### 作用域
作用域约束的是命名空间及固定状态的作用范围，具体规则如下：
- 对于同一个作用域内私有概念的访问，可直接使用其名称访问。
- 对于任意作用域内的公开概念的访问，可基于当前的相对路径进行访问（`.`代表当前模块）。如果想要在某个作用域导出概念，可直接约束该作用域下的那个想要导出的概念。

想要为一个概念施加**内联作用域**（文件内的作用域），就需要用花括号内填充若干语句。单独在一行前使用左花括号（`{`）直到遇到下一个右花括号（`}`）的作用域为**匿名内联作用域**，仅起到命名空间隔离的作用。想要将其绑定到一个概念上，需用点号（`.`）连接两个内联作用域的字面量形式或其他含有或没有内联作用域绑定的概念单独作为一个语句，这样右边作用域内的导出概念会被左边作用域继承且右边作用域会自动导入左边作用域内的所有导出的概念。没有导入的情况下，内联作用域访问父作用域也需用相对路径访问。

**模块**就是以系统文件树为基础的具有路径的懒加载作用域（如果一个0RO文件导出了名称为它的去掉后缀的路径的概念，则会将该概念放置在其文件夹的路径代表的模块中。但是也可以导出其他的概念，只是只有在使用其文件名称的那个概念时才可出现在其文件夹的路径代表的模块中）。且导入后的概念会自动转换为自变量。
### 概念详解
对于概念范围的选定，更加详细的解释如下：
>有一个待定概念P，P是概念C的集合，C又是纯原子概念A的集合，也就是说，C属于P，A属于C。一开始，所有概念都是P，但是等到解析结束的时候，解析器会自动将这个待定概念P坍缩为在已有约束下能覆盖最多概念的概念C，这个概念C是纯原子概念A的集合，代表着概念C在关系r中与另一个概念C'中所有A的纯原子概念都能与C'的A'产生联系。
